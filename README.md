🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides insights such as detected skills, job-role recommendations, resume match score, missing skills, and personalized feedback.

🚀 Live Demo

🌐 Live Application: https://resume-analyzer-5g1n.onrender.com

📌 About The Project

AI Resume Analyzer is a web-based application built using Python and Flask.

Users can upload their resume in PDF format, and the application automatically extracts the resume content and analyzes it using Natural Language Processing (NLP).

The system identifies relevant skills, calculates job-role compatibility, highlights missing skills, and provides feedback to help users improve their resumes.

 ✨ Features

- 📄 Upload resume in PDF format
- 🔍 Extract text from resumes
- 🧠 NLP-based name detection using spaCy
- 💻 Detect technical and soft skills
- 📊 Calculate resume/job match score
- 💼 Recommend suitable job roles
- ❌ Identify missing skills
- 💬 Generate personalized feedback
- 📈 Visualize match score using a doughnut chart
- 🌐 Web-based interface
- ⚡ Lightweight Flask backend
